Controls and privacy

Connect a controller and press a button. Or use WASD to move; mouse to aim; left/right click for R2/L2; Space = Cross; C/Ctrl = Circle; R = Square; E = Triangle; Q/G = L1/R1; Shift/V = L3/R3; 1–4 = D-pad. Escape releases the mouse. PS, Share, Options and touchpad buttons stay with the host. Click the video or Capture mouse to enable aiming.

You share one controller with the host. This does not create a second local player. The host and invited peers may learn each other's public IP through WebRTC. The host can revoke access at any time. Never enter a PSN password, account ID or pairing code on this page.
