Pair your console

  1. PS5: Settings → System → Remote Play. Enable Remote Play and open Pair Device / Link Device. PS4: Settings → Remote Play Connection Settings → Add Device.
  2. In Chiaki, press +. Select a discovered console, or enter its local IP address. Find the address in the PlayStation's network settings.
  3. Use the account active on the console and enter the fresh eight-digit pairing code. Leave the console's pairing screen open until pairing finishes.
  4. Select your saved console to start a stream. No need to pair again each day.
Username, account ID and pairing code are different. Your PSN username is your public online name. The account ID is its technical identifier. The pairing code is the temporary number on the TV. You never enter your PSN password here.

Automatic username lookup sends that public name to an external service. Expand Enter an account ID manually if you already have an ID or prefer to avoid the lookup. A failed lookup does not prevent manual pairing.

Start and stop safely

Launch Chiaki-NG Web from the Windows Start menu. The tray icon keeps its local server running. Closing a browser tab ends that tab's stream; use the tray menu to stop the server too.

Use only one Remote Play client or browser stream per console. Close other Chiaki/Remote Play sessions before connecting. The stream's × button disconnects, or exits fullscreen first. If asked about sleep, choose No to leave the console on.

The ? button reopens this guide. Show details reveals a console's address and ID locally; hide them again before taking screenshots.

The game decides what controller buttons do. Mouse input still emulates a stick: in-game turn limits and aim acceleration apply. If slow movements do nothing, raise dead-zone compensation. If they jump, lower it. Start at 12% and adjust sensitivity to taste. Disable the PC preset to restore your custom bindings.

Virtual pad: the stream toolbar can show touch controls for a touchscreen. The virtual-pad editor lets you adjust their position, size and opacity. PC mode suppresses the virtual pad while active.

Source picture / low latency: use this Stream preset for the original decoded picture without sharpening or denoising. It requests 1080p60 H.265 at 40 Mbps and hardware decoding. Restart the stream after selecting it. Disable external Lossless Scaling frame generation while diagnosing spikes; the checkbox only prepares windowed mode and cannot stop the external app.

The backtick sidebar now shows pending decoder frames, the last receive-to-decode time, resynchronizations and skipped pictures. These measure the browser decode pipeline, not total console-to-screen latency. Temporary bursts retain compressed reference frames. A backlog of 8 frames or over 150 ms triggers a fresh keyframe; this can briefly interrupt the picture while recovery arrives. It prevents old video from accumulating, but cannot remove network loss or an overloaded GPU.

A clearer, smoother picture

High quality LAN

1080p, 60 fps, H.265, 50 Mbps requested. A good starting point for a strong home network.

Clean fog / dark scenes

80 Mbps requested, 10% sharpening and 45% edge-aware noise reduction. Try it when fog or shadows look grainy.

More bitrate gives the encoder room for detail. It does not force a constant rate: a static home screen may use only a few Mbps. The backtick sidebar reports requested bitrate separately from the received video rate.

Sharpening increases edge contrast; too much can emphasize artifacts. Noise reduction smooths similar neighboring pixels; too much can soften textures. Set either to 0 to disable it. There is no temporal blending. These filters require WebGL; a 2D fallback displays video without the filters.

Restart the stream after changing resolution, fps, codec or bitrate. Picture filters apply to new frames immediately. This client requests up to 1080p; extra bitrate or sharpening cannot turn it into native 4K.

What every settings tab does

General — language and session behavior

Language: English or French UI. Disconnect action: leave the console on, put it to sleep, or ask. Action on suspend: what to do when the app suspends. Audio/Video: enable or disable either stream. Discovery: search the local network for consoles. Leave it enabled for easy setup.

Video — decoding and window shape

Hardware decoder: Auto lets the browser choose; prefer-hardware asks the GPU to decode, while prefer-software uses CPU decoding. Window/display mode: fit preserves the picture with possible borders; stretch/fill changes its shape; crop can cut off edges. Start with fit. Fullscreen and double-click behavior are controlled here too. The disabled legacy Render Preset names do not affect this browser renderer; use Stream sharpening and noise reduction instead.

Stream — resolution, codec, bitrate and filters

Console: PS4 or PS5. Resolution: picture size; 1080p has the most source detail. FPS: 60 is smoother; 30 uses less data. Codec: H.265 is efficient on supported browsers; use H.264 if decoding fails. Bitrate: requested data rate in kbps; 50,000 means 50 Mbps. Use a preset before experimenting. Sharpening/noise reduction are explained above.

Lossless Scaling: external mode keeps new streams windowed and offers a launch link for your installed Windows app. Enable LSFG there yourself. It can add displayed frames, GPU load and latency; it does not increase console detail or input rate. Avoid stacking sharpening in both apps.

Audio/Wifi — buffering and network tradeoffs

The audio buffer holds a short amount of sound. A larger buffer can reduce crackles but adds delay; start with the default. Network/Wi-Fi options are advanced tuning controls. Reduce bitrate first if video and audio stutter together. These options cannot repair packet loss on the console-to-PC link.

Consoles — saved devices and account IDs

Manage saved/discovered consoles and their account information. Keep registration keys private. Changing picture settings does not require re-pairing. Do not delete a saved console merely to troubleshoot a busy-session error.

Keys — keyboard, mouse and shortcuts

Enable the PC preset, or click a binding to capture your own key/mouse input. Reset All Keys restores defaults. Sensitivity changes mouse speed; invert Y reverses vertical look; movement selects the left/right stick or none. Mouse-touchpad mode is separate from camera aiming. F8 controls capture and backtick shows the active bindings.

Controllers — physical gamepad settings

This tab shows controller detection status. The first controller returned by the browser is used; connect it and press a button to wake detection. Browser support determines features such as rumble. Use Place buttons to edit the virtual pad on a touchscreen; Reset layout restores it. This tab does not provide physical-pad calibration.

Config — advanced connection and account options

The proxy URL is the network bridge between the browser and console; leave it blank for this local installation. PSN account-ID defaults help with later pairings. Home proxy, sharing and authenticated deployment settings are for advanced setups. You do not need router port forwarding for ordinary local play.

Play with a friend online

Start your console stream, then press Online play. You need your own public invitation server; the separate Online Play guide explains its one-time Docker/TURN setup. Paste its HTTPS address and host key, create a temporary invite, then approve guests as Watch only or Let play. Only one guest can control at a time; you share one controller. Use Stop online to revoke everyone.

Never expose the local app or console ports to the internet. Invites do not include console keys. Start at 720p, keep this tab visible, and invite only trusted friends. This adds encoding work and network delay.

Keep the app updated

Open Settings → General → App updates, or choose Check for updates from the tray menu. Automatic checks run after startup and every six hours; you can turn them off. When an update appears, read its release notes and choose Download and install after finishing your game. It verifies the download, closes the stream, updates and reopens the app. Pairings and settings are kept.

Install version 1.10.3 once to get this feature. Portable/source builds use the download link instead of automatic installation. Updates include browser community previews from this GitHub repository.

If connecting fails

  1. Close other browser streams, desktop Chiaki and the official Remote Play app using that console.
  2. Keep the console on and Remote Play enabled. Check that PC and console are on the same router.
  3. Read the persistent Connection stopped message on the home screen. Use Try again after fixing the cause.
  4. For pairing, reopen the console's pairing screen and use its fresh code. For an unavailable account lookup, enter the account ID manually.
  5. For a black picture, try H.264 or Auto decoding. For stutter, lower bitrate and use Ethernet where possible.

Keep console IDs, account IDs and pairing codes out of screenshots. Never share the local database or registration keys in a bug report.
